# 구매 전환 예측 소표본 실행 검증

팀 `dev`에서 분리한 검수 사본에 기존 구매 로지스틱 모델 코드와 학습 코드를 가져와, 가상 입력으로 학습·저장·재호출을 확인한다.

저장소 최상위에서 NumPy와 scikit-learn이 설치된 구매 학습 환경으로 실행한다.

```text
python -B -m unittest discover -s ml/conversion_model/tests
```

1. 구매·미구매가 각각 포함된 학습 4행을 `C=0.1`로 학습하고, 날짜가 겹치지 않는 검증 4행을 사용한다.
2. 모델·변환 기준을 임시 JSON에 저장한다. 다시 읽은 모델로 동일 입력을 예측하고, 행동 목록으로 호출한 결과와 입력 6개를 직접 전달한 결과를 대조한다.
3. 새 프로세스에서 `ml.conversion_model.models.logistic.predict`를 호출해 구매 확률·쿠폰 조건·모델 파일 식별값을 확인한다.
4. 검증 자료를 미구매만 있는 경우와 구매만 있는 경우로 나눠 각각 평가·저장·재로딩이 되는지 확인한다. 두 경우 모두 학습 자료에는 구매와 미구매가 포함된다.

검증용 JSON은 임시 폴더에 저장한다. 운영 모델, 전체 10월 학습, 실제 팀 API 연결은 이 시험과 별도로 관리한다.
