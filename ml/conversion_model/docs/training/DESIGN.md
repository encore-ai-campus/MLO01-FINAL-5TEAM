# 구매 전환 예측 10월 학습

두 모델은 같은 사용자 명단과 같은 구매 정답으로 학습한다. 로지스틱 회귀는 행동 순서 입력 6개를 사용한다. 비교용 LightGBM은 조회·장바구니 횟수, 시간 간격, 현재 상품 반복 조회, 가격, 브랜드, 카테고리 등 11개 입력을 사용한다. 가격 0은 결측으로 처리한다. 브랜드·카테고리 결측은 그대로 두며 검증에서 처음 등장한 값은 별도 번호로 처리한다.

| UTC 기간 | 역할 |
| --- | --- |
| 2019/10/01~20 | 모델과 입력 변환 기준 학습 |
| 2019/10/21~26 | 검증과 LightGBM 조기 종료 |
| 2019/10/27~31 | 후속 개발 평가 |

학습·검증은 각 구간 종료 시각보다 먼저 확정된 구매 정답만 사용한다. 두 모델의 입력이 모두 유효한 예측 행만 공통으로 사용하며, 학습과 검증에 같은 세션을 넣지 않는다. 실제 10월 학습, 개발 평가, 장바구니 규칙과의 성능 비교는 후속 작업에서 진행한다.

사용자 명단 설정의 기본값은 2%(200bp)다. 측정 결과에 따라 다른 비율을 선택하려면 같은 명세에 해당 사용자 명단과 체크섬을 등록하고 설정값을 변경한다. 로지스틱 회귀의 C는 0.1, LightGBM의 시드는 42다.
