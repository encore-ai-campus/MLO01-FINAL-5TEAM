# 인프라 작업별 선택 실행 설계

VM 생성, AWS 자원 생성, 서비스 설치를 각각 선택할 수 있도록 설계한다. 현재 저장소에는 자동화를 위한 폴더를 마련했다. [전체 폴더 구조](../README.md#폴더-구조)

| 수행하려는 작업 | 선택할 도구와 대상 | 실행 범위 |
|---|---|---|
| 홈서버에 VM 한 대 생성 | VMware의 공통 Ubuntu 템플릿과 대상 VM 설정 | 지정한 VM의 CPU·메모리·디스크를 적용한다. [VMware 구축 절차](vm/README.md) |
| 하이브리드용 AWS 워커 생성 | Terraform의 워커 스택과 사용할 VPC·서브넷 | 독립적으로 생성·삭제할 자원 묶음마다 루트 스택과 상태를 나누고 공통 모듈은 공유한다. [환경별 자원 배치 계획](architecture/cost/AWS·홈서버_Kubernetes_비용_계산.md) |
| 기존 VM 또는 EC2에 Kafka 설치 | Ansible 환경 인벤토리, 대상 호스트, Kafka 플레이북 | 홈서버·하이브리드·클라우드 중 환경을 고르고 서비스 역할과 의존성만 적용한다. [설치 환경 설계](ansible/environment/README.md) |
