# Nextcloud 환경 설정 예제

| 항목 | 내용 |
|---|---|
| 경로 | [`srcs/dev/nextcloud/.env.example`](../../../../srcs/dev/nextcloud/.env.example) |
| 시그니처 | `KEY=VALUE` |
| 파라미터 | `NEXTCLOUD_IMAGE` (웹·Cron 이미지), `MARIADB_IMAGE` (DB 이미지), `NEXTCLOUD_ADMIN_USER` (초기 관리자 계정명) |
| 호출 | 복사한 `.env`를 [`compose.yaml`](compose.yaml.md)에서 읽는다. |
| 기능 | 서버의 `.env`에 복사할 설정 예제를 제공한다. |
